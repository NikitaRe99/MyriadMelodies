# Темы и язык

Встроенный каталог расширен с 14 до 25 тем из сохранённых настроек Debug.
Старые записи этих 11 тем объединяются со встроенными по имени без дублей;
изменения прежних встроенных тем сохраняются.
Исходный профиль скопирован в `artifacts/new-themes/debug-palettes.json`.

Темы в раскрытом списке можно перетаскивать. Alt+↑/↓ перемещает
выделенный пункт на одну строку. Текущая активная тема остаётся выбранной.
Порядок хранится вместе с темами в `custom-color-themes.json` и переживает
перезапуск; при ошибке записи перемещение отменяется.

В настройках доступен выбор Русский / English. При первом запуске
используется язык интерфейса Windows: русский для семейства `ru`,
английский для всех остальных. Старый файл настроек без поля Language
тоже получает этот выбор. Ручной выбор сохраняется в `overlay-settings.json`
и имеет приоритет над системным языком.

Перевод применяется к главному окну, состояниям захвата, диалогам,
подсказкам и встроенным названиям тем. Английские названия переписаны
с предоставленных скриншотов игры в `Новая папка` и перечислены
в `MyriadMelodies/BuiltInThemeNames.cs`. Пользовательские названия и назначения
клавиш не переводятся. Нейтральные ресурсы конструктора остаются русскими;
перевод накладывается при запуске и переключении языка без перестройки окна.

Для перемещения окна подходят заголовок, подписи и свободные участки
панелей. Кнопки, поля, списки и зоны сохраняют собственные действия.
Индикаторы среднего цвета и нажатия в карточках зон рисуются круглыми.
