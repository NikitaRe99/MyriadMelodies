## Русский

**MyriadMelodies** — компактный помощник для ритм-игры в Genshin Impact.
Он захватывает окно игры или экран, распознаёт цвета нот в шести зонах
и нажимает назначенные клавиши. Чтение памяти игры не используется.

- Вертикальный режим и режим распространения.
- Зоны для 16:9, 21:9, 16:10 и 4:3.
- 25 встроенных тем, добавление и редактирование своих, изменение порядка.
- Настраиваемые клавиши, предпросмотр зон и состояния нажатия.
- Русский и английский интерфейс, прозрачность и окно поверх игры.
- Настройки в LocalAppData или рядом с EXE.

**Две версии для Windows x64:**

- **Полная версия** — работает без установки .NET.
- **Компактная версия** — требуется [.NET Desktop Runtime 10 x64](https://dotnet.microsoft.com/en-us/download/dotnet/10.0).

Остальные библиотеки встроены в обе версии. Нужны Windows 10 версии 2004
или новее либо Windows 11. Для отображения поверх игры используйте
оконный режим или режим без рамки. Нажмите «Старт» и вернитесь в игру:
когда игра неактивна, нажатия приостанавливаются.

[Русское описание и скриншоты](https://github.com/NikitaRe99/MyriadMelodies/blob/main/README.md)

Если хотите поблагодарить в игре — **UID 731852725**.

## English

**MyriadMelodies** is a compact assistant for the Genshin Impact rhythm game.
It captures the game window or a display, detects note colors in six regions
and presses your assigned keys. It does not read the game's memory.

- Vertical and spread modes.
- Region layouts for 16:9, 21:9, 16:10 and 4:3.
- 25 built-in themes, custom theme creation/editing and reordering.
- Configurable keys, region previews and key-state indicators.
- English/Russian UI, adjustable opacity and an always-on-top window.
- Settings in LocalAppData or beside the EXE.

**Two Windows x64 versions:**

- **Full version** — works without installing .NET.
- **Compact version** — requires [.NET Desktop Runtime 10 x64](https://dotnet.microsoft.com/en-us/download/dotnet/10.0).

Other application libraries are bundled in both versions. Windows 10 version
2004 or later, or Windows 11, is required. Use windowed or borderless mode
for the overlay. Click **Start** and return to the game: key presses pause
while the game is inactive.
