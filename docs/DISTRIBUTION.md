# Две версии EXE

Сборка для пользователя:

```powershell
./tools/Publish.ps1
```

В `artifacts/release` создаются:

- `MyriadMelodies-standalone-win-x64.exe` — полная версия со встроенным .NET 10.0.14.
- `MyriadMelodies-runtime-required-win-x64.exe` — компактная версия для установленного .NET Desktop Runtime 10 x64.
- `SHA256SUMS.txt` — контрольные суммы этих двух файлов.

В обеих версиях остальные библиотеки приложения включены в EXE.
Профили `SingleFile` и `RuntimeRequired` также доступны в Visual Studio.
Исходные результаты находятся в `artifacts/publish/win-x64` и
`artifacts/publish/runtime-required-win-x64` соответственно.
Неиспользуемый код не обрезается: WinRT и JSON используют динамические типы.

Все встроенные темы и их цвета включены в EXE. Изменяемые настройки
автоматически сохраняются в выбранном месте. По умолчанию:

```text
%LOCALAPPDATA%\MyriadMelodies\overlay-settings.json
%LOCALAPPDATA%\MyriadMelodies\custom-color-themes.json
```

Первый файл содержит язык, выбранный источник/режим/тему, назначение
клавиш, прозрачность и другие параметры окна. Второй — собственные темы,
изменения встроенных тем и порядок списка. Существующие настройки
подхватываются автоматически и сохраняются при обновлении EXE.

Поле «Хранение» в настройках позволяет выбрать «Рядом с EXE».
Тогда оба JSON-файла и маркер `MyriadMelodies.portable` сохраняются рядом
с приложением. Переключение копирует текущие настройки и полный каталог
тем; старые копии остаются на месте. Если запись не удалась, место не
меняется. Перенос всей папки с маркером сохраняет переносимый режим.
Для возврата в LocalAppData выберите этот пункт в списке: маркер удаляется.
Старые файлы из `%LOCALAPPDATA%\ScreenCaptureTool` автоматически читаются
при отсутствии новых файлов в MyriadMelodies.

Для распространения достаточно одного EXE. При запуске .NET может распаковывать нативные компоненты
во временный каталог пользователя; вручную обслуживать их не требуется.

Проверка готового файла:

```powershell
./tools/Test-PublishedApp.ps1
./tools/Test-PublishedApp.ps1 -Executable ./artifacts/publish/runtime-required-win-x64/MyriadMelodies.exe -RuntimeRequired
```

Скрипт проверяет файлы выдачи, дожидается главного окна и штатно закрывает
приложение. Полная версия запускается с недоступным `DOTNET_ROOT`,
компактная — с установленным .NET.
Захват и отправка клавиш не запускаются.
